# Essential Hacking & Security Books

## Core Hacking Books (Must-Read)

### Web Application Security
| Title | Author(s) | Why |
|-------|-----------|-----|
| **The Web Application Hacker's Handbook (2nd Ed)** | Stuttard & Pinto | The definitive web hacking reference |
| **Real World Bug Hunting** | Peter Yaworski | Bug bounty field manual with real case studies |
| **OWASP Web Security Testing Guide** | OWASP | Free, comprehensive testing methodology |
| **Web Security Academy** | PortSwigger | Free interactive labs (best hands-on resource) |

### Binary Exploitation
| Title | Author(s) | Why |
|-------|-----------|-----|
| **Hacking: The Art of Exploitation (2nd Ed)** | Jon Erickson | Classic introduction to exploitation |
| **The Shellcoder's Handbook** | Anley, Heasman, et al. | Discovering and exploiting security holes |
| **Practical Binary Analysis** | Dennis Andriesse | Modern binary analysis techniques |
| **Gray Hat Hacking (6th Ed)** | Harper, Harris, et al. | Comprehensive ethical hacking guide |
| **Binary Exploitation** | LiveOverflow | (Online course) Practical exploit development |
| **0day Security** | Wu & Chen | Advanced software vulnerability exploitation |

### Operating System / Kernel Security
| Title | Author(s) | Why |
|-------|-----------|-----|
| **Windows Internals (Part 1 & 2)** | Russinovich, Solomon, Ionescu | Essential for Windows exploitation |
| **Linux Kernel Development** | Robert Love | Understanding Linux kernel internals |
| **Understanding the Linux Kernel** | Bovet & Cesati | Deep kernel architecture reference |
| **Mac OS X Internals** | Amit Singh | Complete OS X system architecture |

### Network Security
| Title | Author(s) | Why |
|-------|-----------|-----|
| **Network Basics for Hackers** | OTW (Hackers Arise) | How networks work and break |
| **Attacking Network Protocols** | James Forshaw | Network protocol security analysis |

### Cloud / Infrastructure
| Title | Author(s) | Why |
|-------|-----------|-----|

### Malware / EDR / Red Team
| Title | Author(s) | Why |

### Cryptography

## Free Online Resources

### Complete Learning Paths
- **PortSwigger Web Security Academy**: portswigger.net/web-security — Interactive web security labs
- **pwn.college**: pwn.college — Binary exploitation and V8 exploitation challenges
- **Hack The Box**: hackthebox.com — Hands-on penetration testing labs
- **TryHackMe**: tryhackme.com — Guided security learning paths
- **OWASP WSTG**: owasp.org/www-project-web-security-testing-guide/ — Testing framework
- **websec.fr**: PHP web security challenges
- **cryptopals.com**: Crypto challenges (famous "Matasano crypto challenges")

### Video Training
- **LiveOverflow** (YouTube): Binary exploitation, browser hacking, CTF writeups
- **IppSec** (YouTube): HTB walkthroughs and exploit development
- **John Hammond** (YouTube): Malware analysis and CTF
- **STÖK** (YouTube): Bug bounty methodology
- **NahamSec** (YouTube): Bug bounty live hacking
- **The Cyber Mentor** (YouTube): Practical ethical hacking
- **Alisa Esage** (YouTube): Browser exploitation workshop (VXCON 2024)
- **Gynvael Coldwind** (YouTube + LiveStream): CTF writeups, 0-day analysis

### Knowledge Bases
- **HackTricks**: hacktricks.wiki — Living pentesting book
- **PayloadsAllTheThings**: github.com/swisskyrepo/PayloadsAllTheThings — Payload collection
- **GTFOBins / LOLBAS**: Unix/Windows binaries for privilege escalation
- **Exploit Notes**: exploit-notes.hdks.org — Structured exploitation guides
- **HighOn.Coffee**: Pentesting notes and methodology
- **Pentest Monkey**: Cheatsheets for post-exploitation
