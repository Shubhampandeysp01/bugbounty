## How to Use This Path

1. Pick a **track** (web first recommended → then binary or cloud).
2. For each module, open 1–2 repos and complete linked free labs.
3. Map techniques to **Case Studies** in this app (e.g. SSRF → ProxyLogon).
4. Log progress in Learn → mark lessons done; keep notes on what pattern you practiced.
